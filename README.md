## Magic Chess GoGo Joki

Landing page untuk jasa joki Magic Chess GoGo.

Website berfokus pada branding, informasi layanan, bukti hasil joki, FAQ, dan pengarahan calon customer ke WhatsApp. Website tidak menyediakan transaksi, checkout, login, database, atau backend.

### Teknologi

- React
- Vite
- JavaScript
- CSS
- React Router dependency tersedia untuk pengembangan berikutnya

### Fitur saat ini

- Single-page layout
- Hero section dengan artwork lokal
- Navbar responsive desktop dan Android
- Hamburger menu dengan animasi dropdown
- Active navigation berdasarkan posisi scroll
- Smooth scroll dan scroll snap antar-section
- Favicon dan brand asset lokal
- Responsive layout untuk desktop, tablet, dan mobile

### Menjalankan project

Install dependency:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Build production:

```bash
npm run build
```
